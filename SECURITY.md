# Security reports

Report suspected vulnerabilities using GitHub's private vulnerability reporting form when it is available. Include the affected version, operating system, Python version, impact and a minimal redacted description. If the form is unavailable, use a public issue only to request a private contact method and keep the vulnerability details private. [Private vulnerability report](https://github.com/devilanhu-blip/origin-scientific-plotting-skill/security/advisories/new)

For ordinary bugs, use the bundled simulated example and open a GitHub issue. Keep private scientific records, authorization receipts, identifying local paths, license information and credentials out of public reports. [GitHub Issues](https://github.com/devilanhu-blip/origin-scientific-plotting-skill/issues)

The offline command processes local files selected by its operator. Store drafts in a private writable directory. Local draft plans may contain measured values and absolute source paths. Public release assets are assembled only from the reviewed inventory.
