# Release notes · v0.1.0-alpha.1

**Release type** · Public GitHub pre-release for `devilanhu-blip/origin-scientific-plotting-skill`.

## English

Inspect the bundled simulated heating and cooling CSV on Windows x64, generate a traceable two-series plan and render a static PNG with symmetric Y error bars. Compare three reusable styles and save local style revisions. [PowerShell quick start](../README.md)

`--visibility managed` records curve and error-bar pairs in the plan. The PNG displays both series. This Alpha runs without Origin and has no Origin execution connector, editable OPJU output or Origin-native export. Native results for earlier versions apply only to those versions. [Validation scope](validation.md)

## 简体中文

在 Windows x64 上检查随包的模拟升降温 CSV，生成可追溯的双系列绘图计划和带对称 Y 误差棒的静态 PNG。可比较三种预设，并在本机保存风格版本。[PowerShell 快速入门](../README.zh-CN.md)

`--visibility managed` 只记录曲线与误差棒的配对关系。PNG 同时显示两组曲线。此 Alpha 无需 Origin，包内也没有 Origin 执行连接层，无法生成可编辑 OPJU 或调用 Origin 导出。历史版本的原生结果仅适用于当时受测版本。[验证范围](validation.md)
