# Reuse a lab style without changing the experiment

**Question.** A lab wants a presentation version today and an exact replay of an older style after its shared profile changes.

**Reproduce.** Follow the [style walkthrough](../styles.md) on the same simulated run. Save its customized draft as a named lab style, append edition 2, then use the edition-1 selector on a fresh draft. Compare the saved appearance snapshot and scientific data sections. The style and legend may change. The source identity, selected measurements, stage order, units and Y-error definition must agree across all three profiles.

The [gallery evidence](../gallery/snapshots.json) records the plans and appearances for the examples. A style name by itself follows the latest edition. An explicit edition is necessary to reproduce a specific previous lab choice. Any new CSV requires its own column selection and uncertainty definition.
