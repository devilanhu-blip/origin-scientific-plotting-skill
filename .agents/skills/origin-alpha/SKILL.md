# 双系列误差棒离线草图

在已选 Windows x64 CPython 3.12 虚拟环境中调用本目录的 `scripts/origin_trial.py`，参数使用 `-I -B -X utf8`。从[项目中文入口](../../../README.zh-CN.md)核对安装与首次预览。用 `doctor` 检查当前解释器、Pillow 和字体，使用 `inspect` 确认用户点名的 CSV 来源与准确表头。随包样例需标为 SIMULATED。

1. 核对原始行、样品、阶段、X/Y 数值、量与单位和误差列。只有资料明确给出 Y 同单位、非负、逐点对称绝对半宽与形成依据时才能连同误差绘制。根据本次数据选择半宽含义。
2. 对两个系列或连续阶段分别保留采集顺序、重复 X 和阶段边界。记录用户为本次选择的主线及所属误差成组显隐。离线 PNG 是两组均可见的静态图。
3. 调用 `draft`，将 inspect 得到的源文件 SHA-256 绑定到草稿。实际打开输出的 `preview-1.png`，向用户展示并说明两条图例、单位、数据行和误差含义。风格修订从用户看过的草稿生成，核对科学计划一致。可用风格和版本选择见[风格说明](../../../docs/styles.md)。
4. 每份新数据重新确定列、误差、类别和用途。对仅给出统计量名称、单位冲突、误差归属不清晰或超出双系列范围的部分，请用户补充。
5. 本公共候选的交付止于离线草图。实机 OPJU、编辑重开、正式导出的证据范围见[验证摘要](../../../docs/validation.md)。
